- Google logo: [official Google Identity asset](https://developers.google.com/static/identity/images/g-logo.png), used with the [Google sign-in branding guidance](https://developers.google.com/identity/branding-guidelines).

- Google Sans Medium: [Google Fonts distribution](https://fonts.googleapis.com/css2?family=Google+Sans:wght@500&display=swap&text=Continue%20with%20Google), the provider-generated subset for this button's label; SIL Open Font License 1.1, see [OFL.txt](OFL.txt). The original font is 1.9 MB; this official subset is 4 KB.

These files ship locally. Sign-in controls do not load third-party scripts, fonts, or images at runtime. Provider names and logos identify sign-in choices; they do not convey authentication authority.
