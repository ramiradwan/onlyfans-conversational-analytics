Full analysis

Use message-level analysis through the desktop app on this computer.

What Full analysis handles
  • Message content: Full stores supported conversation and participant information, including message text, message and conversation identifiers, participant identifiers and display names, and message timestamps. It can also retrieve supported conversation history when history access is enabled.
  • Same-computer transfer: the extension sends conversation information, including message text, to the desktop analytics service running on this computer. This information leaves the extension but remains on the same computer. The normal conversation dataset is not sent to Provider-hosted analytics or storage infrastructure through the extension’s normal workflow.
  • Local storage and retention: Full-mode information is stored locally in extension storage and in the desktop app. No general automatic expiry period currently applies to the main Full-mode conversation data stored in either location.
  • Deletion boundary: Delete all extension data does not delete conversation information already stored by the desktop app. The extension does not currently provide a complete deletion process for that separately stored desktop data.
  • Other people’s information: messages can contain private or sensitive information about people you communicate with. Enabling Full is your choice to activate this data handling; it is not consent on behalf of those people.

Read the Extension Privacy Notice for the complete description of Full-mode data handling.
