Choose analytics mode

Preview

Preview watches supported chat and message activity to create limited daily counts.

Preview retains limited counts, never message text, conversation identifiers, participant identifiers, participant display names, or other message-level identifiers.

Preview metrics are kept on a rolling seven-day basis and older records are automatically removed.

Preview needs access to the supported platform while it is enabled.

Extension Privacy Notice

Full analytics

Full analytics handles substantially more information than Preview.

  • Message content: Full stores supported conversation and participant information, including message text, message and conversation identifiers, participant identifiers and display names, and message timestamps. It can also retrieve supported conversation history when history access is enabled.
  • Same-computer transfer: the Extension sends conversation information, including message text, to the companion analytics service running on this computer. This information leaves the Extension but remains on the same computer. The normal conversation dataset is not sent to Provider-hosted analytics or storage infrastructure through the Extension’s normal workflow.
  • Local storage and retention: Full-mode information is stored locally in Extension storage and in the companion analytics service. No general automatic expiry period currently applies to the main Full-mode conversation data stored in either location.
  • Deletion boundary: Delete all Extension data does not delete conversation information already stored by the companion analytics service. The Extension does not currently provide a complete deletion process for that separately stored companion data.
  • Other people’s information: messages can contain private or sensitive information about people you communicate with. Enabling Full is your choice to activate this Extension data handling; it is not consent on behalf of those people.

Read the Extension Privacy Notice for the complete description of Full-mode data handling.
