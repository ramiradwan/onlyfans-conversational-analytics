# Packaged companion Noise WASM

This crate supplies the extension's `SnowSession` and `generate_static_keypair` bindings. It fixes `Noise_KK_25519_ChaChaPoly_SHA256` and delegates all cryptography to Snow 0.10.0.

The toolchain is Rust 1.98.1 with the `wasm32-unknown-unknown` target and wasm-bindgen CLI 0.2.128. From `extension/`, run `npm run build:snow` to regenerate `vendor/companion-snow/`. Run `npm run verify:snow` to rebuild in a fresh target directory and require identical generated bytes.

The generator maps complete Rust source filenames to canonical paths, removes the WASM name and producer sections, normalizes upstream license line endings, and sorts dependencies without locale-sensitive comparison. Windows and Linux must rebuild the same vendored bytes; a digest mismatch fails qualification.

The generated release record binds Cargo inputs, source, build helpers, glue, WASM, and upstream notices. The normal extension build verifies this record, bundles the static glue through `runtime/packaged-snow.mjs`, and packages the WASM file under its fixed extension URL. No runtime compiler download or remote executable code is used.

The extension build records the release identity and audits both the binary and production grant trust set in the resulting directory or Chrome archive. MV3 qualification and independent Python interoperability tests consume these same vendored bytes.
